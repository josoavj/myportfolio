## 📦 Installation et Utilisation

### Prérequis
- Flutter 3.1.0 ou supérieur
- Dart SDK 3.1.0
- Un gestionnaire de packages (pub, pub.dev)

### Installation

```bash
# Cloner le repository
git clone https://github.com/josoavj/myportfolio.git
cd myportfolio

# Installer les dépendances
flutter pub get

# Lancer l'application
flutter run
```
