# MyPortfolio v1.2.1

## Description
Application Flutter de portfolio professionnel avec intégration GitHub en temps réel.

- ⚡ **Animations améliorées** - Durées augmentées pour une meilleure fluidité (1.2s fade/slide, 1s scale)
- 📱 **Design responsive** - GridView optimisé pour mobile (3 colonnes)
- 🔧 **Authentification GitHub** - Token authentifié pour accès aux données réelles


- **Frontend**: Flutter 3.1.0+
- **API**: GitHub REST API + GraphQL
- **Responsive**: Mobile-first design (breakpoint: 600px)
- **Animations**: Duration-based avec DelayedAnimation widget
